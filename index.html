Catches Privacy Policy

Last updated: October 23, 2026

Catches is a Chrome extension that saves the current web page as images in the sizes you choose. This policy explains what the extension does with your data.

Summary

Catches does not collect, store on a server, sell or share any personal data. It has no account, no server and no analytics.

What stays on your device

  • Your settings. The sizes you check, custom sizes you add, the light/dark and background-tab toggles, and where you put the focus marker and the Reset button are saved with Chrome's storage. If Chrome sync is on, Chrome syncs them between your own devices.
  • Live preview. While the popup is open, Catches takes a picture of the visible part of the current tab about twice a second and shows it in the popup, so you can choose what stays centered. The preview exists only while the popup is open. It is never saved to disk or sent anywhere.
  • Captured images. Screenshots are made in your browser and saved as a ZIP file in your Downloads folder. They are never uploaded anywhere.
  • Capture status. While a save is running, its progress and result are kept in temporary browser storage so the popup can show them. This is cleared when you close the browser.

How the permissions are used

  • Debugger: attaches to the tab only while it is being captured, to resize the page to each selected size, switch between light and dark mode, scroll the part you chose into the center, and take the screenshot. To do this it reads only the page's address, the position of the element under your marker, scroll positions, and background and text colors. Page content is not collected, stored or sent.
  • Active tab: while the popup is open, reads the address of the current tab so it can be opened in a background tab, and takes the live preview described above.
  • Downloads: saves the ZIP file and opens its folder when you ask. The download bubble is hidden for the moment the ZIP is saved.
  • Storage and offscreen: keep your settings and build the ZIP file inside the browser.

Third parties

Catches does not send data to any third party. The fonts used in the popup are included in the extension and are not loaded from the internet.
